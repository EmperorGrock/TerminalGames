A fun side project of text based games made by nerdy AP Comp Sci students. As of March 17 2026, almost nothing works except TicTacToes.

## Folder Structure

The workspace contains two folders:

- `src`: the folder to maintain source code, all java
- `lib`: the folder to maintain dependencies (which there are none of)

Meanwhile, the compiled class files will be generated in the `bin` folder.

> If you want to customize the folder structure, open `.vscode/settings.json` and update the related settings there.
